# PDF Reference

The project was created from the university assignment PDF located in Downloads:

`Sujet_1_TER___Master_RSA-Securité-5_3a1ecab9af460c8a7ffed5880901dc2a.pdf`

The original PDF was only used as a functional reference and was not modified.

Key requirements reflected in this implementation:

- CIC-IDS2017 dataset.
- Binary network intrusion classification.
- Data preprocessing and cleaning.
- Random Forest, SVM, and simple neural network models.
- Accuracy, precision, recall, F1-score, false positive rate.
- Confusion matrix and comparison between models.
- A small IDS prediction layer.
- A local visualization dashboard.
